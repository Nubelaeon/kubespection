# kubespection

An environment-agnostic, investigation-oriented Kubernetes auditing toolkit built for **SREs, DevOps, SysAdmins, and Security Engineers**. 

`kubespection` provides deep visibility into governance, capacity planning, security posture, orphan resources, and cluster decommissioning risks across any Kubernetes cluster (**EKS, AKS, GKE, or On-Premises**).

> **Note:** This toolkit is **not** a replacement for real-time observability tools like Prometheus, Grafana, Datadog, or Kubecost. It is an ad-hoc investigation and auditing tool designed to answer structural and operational cluster questions instantly.
